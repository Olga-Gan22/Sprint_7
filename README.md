# API-тестирование учебного сервиса «Яндекс Самокат» (Спринт 7)

Автотесты для API сервиса Яндекс Самокат на базе `pytest` + `Allure`. Проект покрывает сценарии работы Courier System и эндпоинты заказов (`v1/orders`).

## Цель проекта

Реализовать набор автотестов для верификации бизнес‑логики учебного стенда:
* создание, авторизация и удаление курьеров;
* создание заказов, получение списка, фильтрация и получение заказа по трек‑номеру;
* сценарии принятия и отмены заказов (с учётом ограничений учебного стенда).

Проект служит основой для дипломной работы: демонстрирует навыки проектирования тестов, работы с фикстурами, генерации тестовых данных и формирования отчётов.

## Стек технологий

* **Язык:** Python 3.x
* **Тестовый фреймворк:** pytest
* **Отчётность:** Allure
* **HTTP‑запросы:** requests
* **Генерация данных:** Faker + кастомные генераторы (`generators.py`)
* **Контроль версий:** Git
* **IDE:** VS Code
